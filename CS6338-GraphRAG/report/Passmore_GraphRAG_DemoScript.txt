This loader writes only accepted extracted assertions into the domain graph. The
structured STIX import is stored separately and cannot supply reference edges to QA.

2:15-3:00 | GRAPH ANALYTICS
SHOW slide 6. RUN in Neo4j Browser:
  CALL gds.pageRank.stream('cti_final', {dampingFactor:0.85,maxIterations:20})
  YIELD nodeId,score
  RETURN gds.util.asNode(nodeId).id AS entity,score
  ORDER BY score DESC LIMIT 5;
SHOW results/analytics_42.json and a vector in results/graph_vectors_42.json.
SAY:
PageRank is the required graph analytics step. Here it measures centrality in this
small selected graph; it is not a threat severity score. I also ran connected-component
analysis and fitted 128-dimensional Node2Vec embeddings for three seeds. Graph
vectors propose neighboring entities. They never count as evidence that a relation
exists. The text embeddings use a different, 768-dimensional vector space.
